# 截图目录说明

这个目录用于存放 GitHub 仓库首页和 GitHub Release 中会用到的截图。

推荐文件：

- `share-screen.png`
- `phone-login.png`
- `phone-chat.png`
- `doctor-terminal.png`

推荐内容：

- `share-screen.png`
  - 桌面端分享页
  - 展示二维码、公网 URL、6 位密码
- `phone-login.png`
  - 手机浏览器打开后的登录页
- `phone-chat.png`
  - 手机端 DeepSeek Harness 对话界面
- `doctor-terminal.png`
  - `npm run doctor` 的通过结果

如果后续要在 `README.md` 中展示，建议使用：
